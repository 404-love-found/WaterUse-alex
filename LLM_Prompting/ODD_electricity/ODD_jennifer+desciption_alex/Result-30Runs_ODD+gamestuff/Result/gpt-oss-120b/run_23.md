**1. Capacitor‑coordination game**  
*Players*: Farmer A (on transformer X) and Farmer B (neighbor on same transformer).  
*Actions*: **Invest** in a capacitor / **Do not invest**.  
*Pay‑off logic*: A capacitor improves voltage for all users on the transformer, but the cost is borne only by the investor. Benefits are realized only if enough farmers on that transformer invest in the same cycle (threshold τ).  

|                | B Invest | B No Invest |
|----------------|----------|------------|
| **A Invest**   | (3,3)    | (1,2)      |
| **A No Invest**| (2,1)    | (2,2)      |

*Explanation*:  
- (3,3) – both invest, threshold met → high reliability for both (ordinal rank 3).  
- (1,2) – A invests alone, threshold not met → A pays cost, gets little benefit (rank 1); B enjoys marginal voltage improvement (rank 2).  
- (2,1) – symmetric to above.  
- (2,2) – no one invests; status‑quo voltage (rank 2) for both.  

*Justification*: ODD +D describes “capacitor adoption only yields shared benefit if enough farmers on the same transformer land on ‘invest’ within the same cycle” and “adoption cost is paid at most once per farmer”. This is a classic coordination dilemma.

**2. Authorization‑contribution game**  
*Players*: Farmer C (considering a formal connection) vs. the **aggregate of other farmers** on the same transformer (treated as a single representative player).  
*Actions*: **Pay** the authorization fee / **Free‑ride** (remain informal).  

|                | Others Pay | Others Free‑ride |
|----------------|-----------|------------------|
| **C Pay**      | (3,3)     | (1,2)            |
| **C Free‑ride**| (2,1)     | (2,2)            |

*Pay‑off interpretation*:  
- (3,3) – everyone contributes → transformer capacity is upgraded, all enjoy reliable electricity (high rank).
