### Title: Farmer Capacitor Adoption and Coordination

### Tension: Farmer Capacitor Adoption Coordination

#### Matrix/Sequential Representation:
**Sequential Game Tree:**

```
          Farmer A
           / \
          /   \
         /     \
       No    Yes
      |      |
      |      |
   Farmer B    Farmer B
     |         / \
     |        /   \
    Yes    No   Yes
     |       |
     |       |
   +1, +1  -1, +1
```

#### Justification:
This sequential game tree captures the strategic tension between two farmers (A and B) deciding whether to invest in a capacitor. The decision to invest in a capacitor is beneficial when coordinated among farmers sharing the same transformer, as it improves voltage stability and pump efficiency. However, an individual farmer might not invest if they believe others will not do so, leading to a free-rider problem. The tree shows that if both farmers choose to invest, they both benefit (+1, +1). If one farmer invests and the other does not, the non-investing farmer benefits while the investing farmer incurs a cost (-1, +1). This represents the strategic interdependence and the free-rider dilemma in capacitor adoption.

### Title: Farmer-Staff Informal Exchange

### Tension: Informal vs. Formal Connection

#### Matrix/Sequential Representation:
**Normal Form Payoff Matrix:**

```
             Staff
            / \
           /   \
          /     \
        Formal  Informal
       |        |
       |        |
Farmer  Formal  -1, -1  0, +1
        Informal +1, 0   0, 0
```

#### Justification:
This normal-form game captures the strategic tension between a farmer and a sub-station staff member regarding the type of connection (formal or informal). If both choose formal, the farmer incurs a cost and the staff incurs effort costs (-1, -1). If the farmer chooses informal and the staff tolerates it, the farmer benefits from reduced costs while the staff incurs no additional effort (0, +1). If the staff enforces formal rules and the farmer attempts an informal connection, the farmer incurs a penalty and the staff incurs no additional cost (-1, 0). If both choose informal, no additional costs or benefits are incurred (0, 0). This reflects the trade-offs between formal compliance and informal tolerance.
