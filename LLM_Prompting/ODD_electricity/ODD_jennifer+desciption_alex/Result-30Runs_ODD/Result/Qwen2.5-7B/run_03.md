### Title: Farmer-Farmer Coordination on Capacitor Adoption

### Tension: Farmer-Farmer Coordination on Capacitor Adoption

### Matrix/Sequential Representation:
**Sequential Game Tree Representation:**

```
                 Farmer A
                 /   \
                /     \
            Invest  Do Not Invest
           /   \      /   \
          /     \    /     \
 Farmer B Invest  (2,2)  (0,3)
           /   \      /   \
          /     \    /     \
 Do Not Invest (3,0) (1,1)
```

### Justification:
This represents the sequential decision-making process where Farmer A and Farmer B must decide whether to invest in a capacitor. The payoff matrix shows that if both farmers invest, they each receive a payoff of 2. If one farmer invests and the other does not, the investor receives a payoff of 3, while the non-investor receives a payoff of 0. If neither invests, both receive a payoff of 1. The sequential nature of this game captures the strategic tension between coordinating investments and the potential for free-riding.
