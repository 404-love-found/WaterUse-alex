| 4 | **Formal request – staff investment (Farmer F ↔ Sub‑station staff S)** | The farmer can **formally request** an authorized connection (paying a fee). The staff then decides either to **invest** in capacity/maintenance (incurring effort) or to **withhold** (saving effort). If the staff invests, the farmer gains reliable electricity; if the staff withholds, the farmer loses the fee but still gets poor service. The reverse (informal request) creates a different payoff pattern (farmer gains more, staff bears cost). This is a **sequential** game: first the farmer chooses request type (formal / informal / none), then staff chooses investment/withhold. | **Sequential** <br>1. Farmer chooses **Request** ∈ {Formal, Informal, No request}. <br>2. Staff observes request and chooses **Action** ∈ {Invest, Withhold}. <br>Payoff pairs are ordinal (4 = best, 1 = worst) for each branch (see matrix below). |  |
